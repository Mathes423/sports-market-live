SPORTS MARKET LIVE V3 — CFB / Men's CBB / NFL

UPLOAD TO GITHUB
1. Extract this ZIP.
2. Open https://github.com/Mathes423/sports-market-live
3. Choose Add file > Upload files.
4. Upload the FOUR files inside this extracted folder (not the folder itself): index.html, sw.js, manifest.webmanifest, icon.svg.
5. Commit changes to main. GitHub Pages redeploys automatically.
6. Wait a few minutes, then reload https://mathes423.github.io/sports-market-live/ (force refresh if necessary).

WHAT IT DOES
Fetches scoreboard data on opening and every 60 seconds while the page is visible. Filters by league, date, game status; displays scores and available team stats. No fabricated scores. Offline fallback for app shell only, not live stats.

IMPORTANT
Uses unofficial, undocumented ESPN endpoints, which may be unavailable, change, or restrict use without warning. Confirm provider permission and terms before distributing publicly or using commercially. CFB group=80 attempts FBS; CBB group=50 attempts men's Division I. Coverage and statistical fields may be incomplete. If live feed is unavailable, the app reports it rather than inventing results. No API keys embedded.
