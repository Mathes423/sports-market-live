About the data: This dashboard requests CFB (FBS), men's Division I CBB, and NFL schedules and scores from publicly reachable, unofficial ESPN endpoints. They are not guaranteed, licensed, or officially supported and can change, limit access, or fail. Scores refresh approximately every 60 seconds while this page is visible. V19 prioritizes live-game box scores, then loads completed-game box scores in small batches. Live box scores are rechecked about every two minutes while the page is visible; completed box scores are cached for the session. Select Load / update box score to request a specific game immediately. Detailed data is cached and may lag behind the scoreboard. Missing stats show —; scheduled games may have no stats. The displayed update time is when your browser last checked, not necessarily when a game event occurred. CBB is men's Division I. No fabricated scores are shown. This is an independent project, not affiliated with ESPN.
